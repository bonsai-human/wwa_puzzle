# wwa_puzzle

WWA（World Wide Adventure）系の見下ろし2Dパズルゲーム。
GitHub Pages 上で動作する静的Webアプリとして実装する予定。

マップ上のリソース（HP・攻撃力・防御力・鍵・オーブ）をどの順序で回収し、
どの敵を倒し、どの扉を開けるかを決める、完全情報のリソース配分パズル。
乱数はなく、実質的には詰将棋にあたる。

## 状態

設計フェーズ。実装はまだ行っていない。

- [docs/design.md](docs/design.md) — 設計ドキュメント（ルール仕様・データ形式・ソルバー・自動生成・デプロイ方針）

## 構成予定

| ディレクトリ | 役割 |
|---|---|
| `src/core/` | 純粋なルールエンジン。DOM・I/O・乱数に依存しない |
| `src/solver/` | 解の探索、詰み検出、ヒント。Web Worker 上で動作 |
| `src/gen/` | マップの自動生成と難易度評価 |
| `src/editor/` | マップエディタ |
| `src/game/` | Canvas 描画・入力・UI |

## 技術方針

TypeScript + Vite + Canvas 2D、テストは Vitest。
サーバーを持たないため、生成もソルバーもすべてクライアント側で実行する。
